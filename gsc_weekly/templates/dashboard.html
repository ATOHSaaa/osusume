初回セットアップ
  1. Google Cloud で Search Console API を有効化
  2. OAuthクライアント（デスクトップ）JSON → credentials/client_secret.json
  3. .env に GSC_PROPERTY_URL=https://example.com/
  4. python -m gsc_weekly auth
  5. このページで「最新レポートを生成」
